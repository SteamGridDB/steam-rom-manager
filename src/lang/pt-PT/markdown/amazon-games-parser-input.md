# Entradas Específicas do Analisador de Amazon Games

## Substituição do Caminho para Amazon Games
Por predefinição, Steam ROM Manager pressupõe que a sua instalação de Amazon Games está localizada em `C:\Users\&#060;username&#062;\AppData\Local\Amazon Games\App\Amazon Games.exe`. Este campo permite-lhe substituir esse caminho se a sua instalação de Amazon Games estiver em outro lugar.

## Iniciar Via Amazon Games

Ao que parece, este botão permite definir se os jogos serão lançados via Amazon Games ou diretamente.
